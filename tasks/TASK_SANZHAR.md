Проект: RL-среда для ИИ-аудитора (Genesis FinTech, условие кейса в файле кейса). Код: `schemas.py`,

в наблюдениях, ошибках, ID и `info` не должно быть подсказок про эталон.

## Задача 1 (первая, от неё зависят Абильмансур и Дармен): пересчёт валют в книге

Сейчас счёт в USD проводится в USD, и в базовую валюту ничего не пересчитывается, поэтому
ошибке курса некуда встать. Сделай так:
- проводки по документам в иностранной валюте идут в базовой валюте (`manifest.base_currency`)
  по курсу из `fx.csv` согласно `policy.fx_rate_date_rule` (локальная дата документа, иначе
  последняя более ранняя), округление `ROUND_HALF_UP` один раз (`schemas.convert_minor`);
- платёж пересчитывается по курсу даты платежа; разница с суммой счёта — на новый счёт
  `4900 FX gain/loss` (добавить в `CHART_OF_ACCOUNTS`), книга балансируется;
- обнови `_verify_clean` (сверка дебиторки в базовой валюте) и тест `_truth_is_semantically_true`;
- дай Абильмансуру и Дармену функцию/хук, через который мутатор FX может подменить курс,
  использованный для конкретной проводки.

Готово, когда: книга сбалансирована, дебиторка сходится, есть тест «пересчёт = convert_minor по
правильной дате, включая выходные», `python check.py` проходит.

## Задача 2: случайные ID и перестановка (15 баллов за парные проверки)

- Новый класс `ShuffledIdScheme(IdScheme)`: случайные, ничего не значащие ID (например
  `L-7f3a2c`, `DOC-91b0e4`), порядок строк перемешан, всё от seed + `salt`.
- Убери подсказку «дубль всегда соседний номер» (сейчас дубль получает DOC-00027 рядом с DOC-00028).
- Тест: для 20 пар (тот же seed, другая схема ID/порядок) oracle получает ту же награду и тот же
  F1 с учётом новых ID; эталон указывает на те же по смыслу записи.
- Повтор seed + те же действия → побайтно одинаковые наблюдения и награды (тест уже есть, расширь).

## Задача 3: оценщик в отдельном процессе

Сейчас агент в том же процессе может достать `env.evaluator._refs`. Сделай `runner.py`:
политика агента запускается отдельным процессом и общается только JSON-строками через
stdin/stdout (`reset` → наблюдение, действие → наблюдение/награда); `Evaluator` и `truth`
живут только в процессе запускателя. Лимиты: 100 шагов, 60 с на эпизод (таймаут → `truncated=true`,
пустой ответ). Тест: агент-процесс не может получить эталон, падение или зависание агента
не ломает запускатель.
